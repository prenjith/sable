1/ I built a small programming language called Sable.

It is designed to be learned in an afternoon and used for real little scripts.

2/ It has classes, closures, pattern matching, pipelines, try/catch, modules,
and thread-based concurrency.

3/ There is a zero-install browser playground:

https://pranavrenjith2-source.github.io/sable-playground/

4/ It also ships native binaries for Linux, macOS, and Windows, plus a pip
package and a Docker image.

5/ The core is self-hosted in Sable, and there is a C bytecode VM for the core.

Repo: https://github.com/prenjith/sable
