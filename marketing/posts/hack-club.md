I made a programming language for Hack Club

Sable is a small language I built for learning and quick scripts. You can try it
in the browser with no install:

https://pranavrenjith2-source.github.io/sable-playground/

It has classes, pattern matching, pipelines, errors, modules, and concurrency.
There is a todo CLI example and a `--test` runner. I also wrote a research kit so
clubs can run short usability sessions and send feedback.

I would love if a few people tried the playground and told me the first thing
that confused them. That is more useful to me than stars.
