# Launch plan

## Goal

Get 100 real users and 10 pieces of feedback in the first week, not a million
views.

## Before launch

- [ ] Tag `v0.14.0` and attach binaries
- [ ] Social card in `docs/social-card.png`
- [ ] README hero and playground link
- [ ] Demo script practiced
- [ ] One good first issue per area (docs, examples, native VM)
- [ ] Reply templates ready for common questions

## Channels and order

1. **Hack Club Slack** — personal, ask for feedback, no hard sell
2. **r/HackClub** — teen-focused story
3. **Show HN** — Tuesday to Thursday, 9–11am ET
4. **r/programming** — technical write-up, not the same text as HN
5. **X thread** — short demos and a playground link
6. **Dev.to** — "building a small language in public" article
7. **Product Hunt** — only after the first feedback round

## Rules

- One post per platform, tailored.
- Reply to every comment for the first two hours.
- Do not mass-DM or cross-post identical text.
- Do not claim full independence or production readiness.
- Ask for specific feedback: syntax, errors, first project.

## Measure

- Playground visits
- GitHub stars and forks
- Issues and discussions opened
- Qualitative quotes about confusion and delight
