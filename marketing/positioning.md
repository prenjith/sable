# Sable positioning

## One line

Sable is a small scripting language you can learn in an afternoon and run
everywhere.

## Who it is for

- Hack Club teens learning to code
- People who want a tiny language for automation and file/JSON work
- Educators who want a first language with modern features

## Why now

- The browser playground removes setup entirely.
- Native binaries exist for Linux, macOS, and Windows.
- Modern features without a huge ecosystem: pattern matching, pipelines,
  classes, errors, modules, and concurrency.
- The implementation is small enough to read and learn from.
- It is built in public, with a self-hosted core and a native VM.

## Trends worth riding

- **Zero-install first**: browser playgrounds win beginners.
- **Single binaries**: Go and Zig made "one file, no runtime" attractive.
- **Modern ergonomics**: pattern matching, pipelines, and sum-type-like errors
  are spreading from Rust/Swift into smaller languages.
- **Build in public**: devlogs and honest limitations get more trust than hype.
- **Teen communities**: Hack Club is a real distribution channel for a first
  language.

## Risks

- No package ecosystem yet.
- Not a performance or systems language.
- Crowded beginner space (Python, JavaScript, Lua).
- The native path is incomplete; do not market it as fully independent.

## Message

Lead with the playground and the "learn it in an afternoon" promise. Show real
scripts (todo, file/JSON) instead of benchmarks. Be honest about what is
missing.
