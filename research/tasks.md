# Task cards

Each card has a goal, a prompt, and success criteria. Pick cards that match the
participant's stated goal, plus one card from a different goal if there is time.

## 1. Hello, Sable (beginner)

Prompt: "Make Sable print a greeting that includes your name."

Success: one line of output.

## 2. FizzBuzz (beginner, automation)

Prompt: "Print the numbers 1 to 15, but print Fizz for multiples of 3, Buzz for
multiples of 5, and FizzBuzz for multiples of both."

Success: correct output for 1 through 15.

## 3. Word count (automation, data)

Prompt: "Count how many times each word appears in a sentence."

Success: a map with word counts.

## 4. Pipeline (data)

Prompt: "Take a list of numbers, keep the even ones, square them, and add them
up."

Success: the correct total.

## 5. Classes (toolbuilder)

Prompt: "Make a Point class with x and y, and a method that returns the distance
from the origin."

Success: a constructed object and a correct distance.

## 6. Errors (toolbuilder, automation)

Prompt: "Write a function that divides two numbers and reports a friendly error
when the divisor is zero."

Success: no crash; a caught error message.

## 7. Match (data, toolbuilder)

Prompt: "Use match to turn 1 into 'one', 2 into 'two', and anything else into
'many'."

Success: correct output for three inputs.

## 8. Modules (toolbuilder)

Prompt: "Put a helper function in one file and use it from another."

Success: the imported function runs.

## 9. Parallel (concurrency)

Prompt: "Start two tasks at the same time, wait for both, and print their
results."

Success: both results printed; no crash.

## 10. Native build (performance)

Prompt: "Compile a small Sable program to a native executable with sablec.py
and run it."

Success: a native binary that prints the expected output.

Note: the native backend covers the core language only. If the participant
reaches lists, classes, or concurrency, record that as a limitation.
