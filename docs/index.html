Sable

A small scripting language with closures, pattern matching, error handling, and a pipeline operator.

tree-walking interpreter · zero dependencies

Open the browser playground →

Quick start

python3 sable.py examples/fizzbuzz.sable
python3 sable.py            # REPL
python3 sable.py --tokens examples/fib.sable
python3 sable.py --ast examples/fib.sable

Programs use the .sable extension. Statements end with semicolons. Comments are // and /* */.

Values and variables

let name = "world";
const pi = 3.14159;
let items = [1, 2, 3];
let user = {"name": "ana", "age": 15};

print(user.name);
user.age = user.age + 1;
print(items[0]);

Types are nil, bool, number, string, list, and map. Maps accept string, number, boolean, or nil keys. Only nil and false are false.

Type annotations

fn area(width: number, height: number): number {
    return width * height;
}

let w: number = 4;
let h: number = 5;
print(area(w, h));

Annotations are optional and checked before the program runs. Use any to opt out, or run sable --check file.sable to check without executing.

Operators

1 + 2 * 3
"a" + "b"
10 % 3
x == y, x != y, x < y
a and b, a or b, not a
count += 1

and and or short-circuit and return one of their operands. Assignment supports = += -= *= /=.

Control flow

if score > 90 {
    print("A");
} else if score > 80 {
    print("B");
} else {
    print("keep going");
}

while i < 10 {
    i = i + 1;
}

for item in items {
    print(item);
}

Functions and closures

fn add(a, b) {
    return a + b;
}

let double = fn(n) { return n * 2; };

fn counter() {
    let n = 0;
    fn next() {
        n = n + 1;
        return n;
    }
    return next;
}

Pattern matching

fn describe(n) {
    match n {
        1 => return "one";
        2 => return "two";
        _ => return "many";
    }
}

Patterns are literals, _ for a wildcard, or a name that binds the matched value.

Errors

try {
    if b == 0 {
        throw "cannot divide by zero";
    }
    print(a / b);
} catch err {
    print("error: " + str(err));
}

Runtime errors are caught as maps with message and line fields. Thrown values are passed through as-is.

Pipelines

let result = nums
    |> filter(is_even)
    |> map(square);

print(result);

value |> f calls f(value). If the right side is a call, the value is inserted as the first argument: value |> f(x) becomes f(value, x).

Modules

import "mathx.sable";

print(square(5));

Imports are resolved relative to the importing file and executed once. Everything the imported file defines becomes available.

Classes

class Point {
    fn init(x, y) {
        this.x = x;
        this.y = y;
    }

    fn length() {
        return sqrt(this.x * this.x + this.y * this.y);
    }
}

let p = new Point(3, 4);
print(p.length());

new creates an object and calls init when it exists. Fields are accessed with dot notation, and methods receive this.

Concurrency

let task = spawn(fn() {
    return 21 * 2;
});

print(wait(task));

spawn runs a function on another thread and returns a task; wait joins it. sleep(ms) pauses the current task. Shared mutable state is not synchronized.

Editor support

The repository includes a minimal language server:

python3 lsp.py

It speaks JSON-RPC over stdio and publishes parse and type diagnostics. The VS Code extension in editors/vscode adds syntax highlighting.

Useful builtins

Read and write files, inspect directories, read environment variables, parse JSON, and work with time and randomness:

write_file("todo.json", json_encode([{"text": "buy milk", "done": false}]));
let items = json_decode(read_file("todo.json"));
print(items[0].text);
print(file_exists("todo.json"));

sable --test dir runs every .sable file in a directory. stdlib/testing.sable provides simple assertions.

Native VM

native/compiler.py compiles the core language to stack bytecode and native/vm.c runs it without Python:

python3 native/compiler.py examples/fizzbuzz.sable -o /tmp/fizzbuzz.sasm
cc -O2 -o native/sable-vm native/vm.c -lm
./native/sable-vm /tmp/fizzbuzz.sasm

It covers numbers, strings, booleans, nil, variables, arithmetic, comparisons, if/else, while, and print. Functions, collections, classes, errors, modules, and threads are the next milestones.

Self-hosting

selfhost/sable.sable is a core interpreter written in Sable. Run it with the host:

python3 sable.py selfhost/sable.sable examples/fizzbuzz.sable

It supports the core language. The first run still needs a seed interpreter; a fully native build needs the C backend to cover lists, maps, closures, and errors.

Native backend

sablec.py compiles the core language to C and builds a native executable:

python3 sablec.py examples/fizzbuzz.sable -o fizzbuzz
./fizzbuzz

It supports numbers, strings, booleans, nil, variables, arithmetic, comparisons, if/else, while, for..in range(...), top-level functions, and print/str/num/len. Lists, maps, classes, match, errors, imports, and concurrency are not in the native backend yet. Full-language native binaries are built with Nuitka in CI.

User research

The repository includes a research kit for short Hack Club sessions: consent and assent templates, task cards, a survey, an observation rubric, and an analysis script.

python3 research/analysis.py research/sample_sessions.csv

The sample data is synthetic. Real sessions should use anonymous IDs and follow the consent templates.

Verification

--verify runs the type checker plus extra static checks: break/continue outside loops, return outside functions, unreachable code, duplicate map keys, and unreachable match arms.

python3 sable.py --verify examples/types.sable
python3 tools/fuzz_parser.py

The test suite includes seeded property tests. This is practical verification, not formal proof.

How it works

Sable is a single-file tree-walking interpreter. The lexer produces tokens with line and column positions, the parser builds an AST with recursive descent, and the interpreter evaluates that AST against a chain of environments. Closures capture their defining environment; return, break, and continue are control-flow signals.

Errors point at the source line:

RuntimeError: undefined variable 'x'
  line 3: print(x);
  ^
